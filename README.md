# Haojie Ye

Personal website and public resume: [linestro.github.io](https://linestro.github.io/).

The site covers my work in AI performance modeling, GPU architecture, and published systems research.

## Edit and preview

The current site is plain HTML and CSS and needs no build step.

- `index.html`: profile, experience, research, and education.
- `style.css`: layout and visual styles.
- `assets/Resume_HaojieYe.pdf`: downloadable resume.
- `resume/main.tex`: editable resume source; see [resume instructions](resume/README.md).
- `assets/papers/`: public research papers.

To preview locally, run `python3 -m http.server 8000` from the repository root and open [localhost:8000](http://localhost:8000).
