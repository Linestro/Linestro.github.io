Deep Learning Performance Architect · NVIDIA

I connect AI workloads with GPU architecture as a Deep Learning Performance Architect at NVIDIA. I build and validate performance models, investigate system bottlenecks, and turn complex results into clear engineering and product recommendations.

My current work spans LLM inference and video generation, architecture tradeoff studies, and AI-agent-assisted performance analysis. I take studies from workload assumptions and simulation through validation and technical explanation, working across architecture, engineering, and product teams.

I earned my Ph.D. in Computer Science and Engineering at the University of Michigan, advised by Prof. Trevor Mudge. My research in hardware-software co-design covers recommendation inference, GPU systems, graph processing, sparse computation, and secure memory, with publications at HPCA, ASPLOS, MICRO, ISCA, VLDB, and PACT.

Selected Research

My academic work pairs workload characterization with architecture and system design to improve the efficiency of data-intensive computation. Selected papers below cover recommendation inference, GPU and memory systems, graph processing, and LLM fine-tuning. See Google Scholar for the full publication list.

HPCA'25 Protocol-Hardware Co-Design · Oblivious Memory

Palermo: Improving the Performance of Oblivious Memory using Protocol-Hardware Co-Design

H. Ye, Y. Xia, Y. Chen, K.-Y. Chen, Y. Yuan, S. Deng, B. Kasikci, T. Mudge, N. Talati
HPCA 2025

Palermo co-designs an oblivious RAM protocol and hardware controller to overlap memory operations while preserving correctness and security guarantees. The paper evaluates how protocol and architecture choices reduce the performance cost of protecting memory access patterns.

Paper PDF
ASPLOS'23 Recommendation Inference · Embedding Reuse

GRACE: A Scalable Graph-Based Approach to Accelerating Recommendation Model Inference

H. Ye, S. Vedula, Y. Chen, Y. Yang, A. Bronstein, R. Dreslinski, T. Mudge, N. Talati
ASPLOS 2023

GRACE clusters an item co-occurrence graph and caches embedding partial sums to reduce recommendation inference memory traffic. It pairs an algorithmic approach to recurring item combinations with a scalable system design.

Paper PDF Code ASPLOS talk
IISWC'24 LLM Fine-Tuning · Throughput and Cost Modeling

Understanding the Performance and Estimating the Cost of LLM Fine-Tuning

Y. Xia, J. Kim, Y. Chen, H. Ye, S. Kundu, C. Hao, N. Talati
IISWC 2024

This work characterizes single-GPU fine-tuning of sparse and dense mixture-of-experts language models. An analytical model estimates throughput and cloud training cost to support infrastructure choices.

Paper
VLDB'24 GPU Systems · Temporal Motif Mining

Everest: GPU-Accelerated System For Mining Temporal Motifs

Y. Yuan, H. Ye, S. Vedula, W. Kaza, N. Talati
PVLDB 17(2), 2023 / VLDB 2024

Everest accelerates temporal motif mining on GPUs through query-specific code generation, runtime load balancing, and multi-GPU graph partitioning. It connects graph-query structure to efficient parallel execution.

Paper Code
PACT'22 Multi-GPU · Remote Memory · Locality

Locality-aware Optimizations for Improving Remote Memory Latency in Multi-GPU Systems

L. Belayneh, H. Ye, K.-Y. Chen, D. Blaauw, T. Mudge, R. Dreslinski, N. Talati
PACT 2022

This work introduces locality-adaptive remote memory transfers and a remote-only cache for multi-GPU systems. The architecture targets remote access latency by matching transfer and caching behavior to workload locality.

Paper PDF
ISCA'22 Graph Pattern Mining · Near-Data Processing

NDMiner: Accelerating Graph Pattern Mining Using Near Data Processing

N. Talati, H. Ye, Y. Yang, L. Belayneh, K.-Y. Chen, D. Blaauw, T. Mudge, R. Dreslinski
ISCA 2022

NDMiner combines near-data execution, compiler support, and memory mapping to accelerate graph pattern mining. The design addresses the irregular memory access and control flow that make this workload difficult to execute efficiently.

Paper
MICRO'22 Temporal Motif Mining · Accelerator Design

Mint: An Accelerator For Mining Temporal Motifs

N. Talati, H. Ye, S. Vedula, K.-Y. Chen, Y. Chen, D. Liu, Y. Yuan, D. Blaauw, A. Bronstein, T. Mudge, R. Dreslinski
MICRO 2022

Mint introduces an accelerator architecture and programming model for temporal motif mining. It exploits parallelism while handling both structural and temporal constraints in graph queries.

Paper
ICS'20 Sparse Matrix-Vector Multiplication · Systolic Arrays

Sparse-TPU: Adapting Systolic Arrays for Sparse Matrices

X. He, S. Pal, A. Amarnath, S. Feng, D.-H. Park, A. Rovinski, H. Ye, Y. Chen, R. Dreslinski, T. Mudge
ICS 2020

Sparse-TPU co-designs sparse matrix packing and a systolic-array architecture to improve sparse matrix-vector multiplication efficiency. The work examines how data representation and hardware support can make better use of array resources.
